The whole thing, step by step

Eight steps. About an hour, most of it waiting for downloads. You will type exactly two commands, both of which you can copy with a button. If you get stuck at any point, the Help page covers every common snag.

Before you start: have the Pi, the memory card, the power supply and your router's admin password to hand. If you are missing something, the shopping list is one page back.

Write the operating system to the card 15 minutes

On your normal computer, download Raspberry Pi Imager from raspberrypi.com/software and install it. Put the memory card in your computer (a card reader if your laptop has no slot), then:

  1. Open Imager and click Choose device → pick your Pi model.
  2. Choose OS → Raspberry Pi OS (other) → Raspberry Pi OS Lite (64-bit). “Lite” means no desktop — this box has no screen, and Lite leaves more room for everything else.
  3. Choose storage → your memory card. Check it twice; the card is erased.
  4. Click Next, then Edit settings when it offers. This part matters:
  • Set hostname to adblockerpro — that is how you will find it later.
  • Set a username and password. Write them down. Use pi as the username if you want the rest of this guide to match exactly.
  • If the Pi will use Wi-Fi, tick Configure wireless LAN and enter your network name and password, plus your country.
  • On the Services tab, tick Enable SSH → Use password authentication. Without this you cannot talk to the Pi at all.

Save, then Write. Go and make a coffee; it takes a few minutes.

If you skip the SSH tick box, you will have to start this step again. It is the single most common mistake.

Plug the Pi in 3 minutes

  1. Put the memory card in the Pi (contacts facing the board).
  2. If you are using a cable, connect the Pi to a spare LAN port on your router.
  3. Plug in the power supply. A green light will flicker — that is it thinking.
  4. Wait three minutes. The very first boot is slow because it resizes the card.

There is no screen and nothing to click. The Pi is now quietly sitting on your network waiting to be talked to.

Connect to it from your computer 5 minutes

You are going to open a text window that is typing on the Pi instead of on your own machine. It is less dramatic than it sounds.

  • Windows: open the Start menu, type cmd, press Enter.
  • Mac: press ⌘ + Space, type terminal, press Enter.
  • Linux: you know where your terminal is.

Then paste this (replace pi if you chose a different username) and press Enter:

ssh pi@adblockerpro.local

It will ask “Are you sure you want to continue connecting?” — type yes. Then it asks for the password you set in Imager. Nothing appears as you type the password. That is normal; type it and press Enter.

“Could not resolve hostname”? Some networks don't do .local names. Find the Pi's address in your router's device list (look for “adblockerpro” or “raspberrypi”) and use that instead: ssh pi@192.168.1.123.

When you see something like pi@adblockerpro:~ $ you are in.

Install adblockerpro 5 minutes

Copy this one line, paste it into that window, press Enter:

curl -fsSL https://raw.githubusercontent.com/ahardkore/adblockerpro/main/deploy/install.sh | sudo bash

It will ask for your password again (it needs admin rights to take over port 53, the DNS port). Then it:

  • downloads the right binary for your Pi,
  • creates a locked-down user for it to run as,
  • steps around the system's own DNS service, which normally occupies that port,
  • installs it as a service so it starts automatically after a power cut,
  • downloads the blocklists and starts filtering.

When it finishes it prints the address of your dashboard. It will look like http://192.168.1.123:8080.

Nothing has changed on your network yet. The Pi is filtering, but nothing is asking it to. That is the next step — and it is the one that matters.

Open the dashboard and run the wizard 5 minutes

On any device in the house, open a browser and go to the address the installer printed (or http://adblockerpro.local:8080).

A welcome wizard appears. It asks you three things:

  • How strict? Choose Balanced unless you have a reason not to. You can change it later in one click.
  • Your router. It shows you the exact address to type into the router — the next step of this guide.
  • A password for the dashboard, so a guest on your Wi-Fi can't switch the filter off.

Leave the browser tab open. You will come back to it to press Run the test.

Give the Pi a permanent address 5 minutes

Your router hands out addresses that can change. If the Pi's address changes after the next power cut, your whole network loses DNS — so pin it down first.

In your router's admin pages, look for DHCP reservation, Static lease, Address reservation or Fixed IP, find the device called adblockerpro, and reserve its current address.

Every router words this differently, but it is always within two clicks of the list of connected devices.

Point your router at the Pi 10 minutes — the important one

This is the step that switches the whole house over. In your router's admin pages, find the DNS server setting — it lives under DHCP or LAN settings, not the internet/WAN settings — and set the primary DNS to the Pi's address. Save, and reboot the router if it offers.

Only list the Pi. If you leave a second DNS server (like 8.8.8.8) in the other box, devices will silently use it half the time and you will see ads and think the project failed.
Router won't let you change DNS? Turn off your router's DHCP server, then open the DHCP tab in the dashboard and turn the Pi's own one on. It hands out addresses and points every device at itself. The dashboard explains each box as you fill it in.

Test it, then forget about it 5 minutes

Go back to the dashboard tab and press Run the test. It checks four things and tells you in plain words what to do about anything that fails.

Devices only pick up the new setting when their lease renews, so give one device a nudge: turn its Wi-Fi off and on, or reboot it. Then watch the Query log — you should see its look-ups appear within seconds, with some of them red.

For a belt-and-braces check from your own computer:

nslookup doubleclick.net

If it answers 0.0.0.0, you are filtered. If it answers a real address, that device is still using the old DNS — reboot it.

That's it. It updates its blocklists every day, restarts itself after a power cut, and needs nothing from you. Check in when you're curious, or when someone shouts “the internet is broken” — in which case press Pause 5 min at the top of the dashboard and see whether it actually was.

Optional extras, once it's working

Bedtime for tablets

Schedules tab: block everything (or just social media) for a group of devices between set hours.

Name your gadgets

Devices tab: turn “192.168.1.34” into “Fire Stick”, then open its report to see what it has been asking for.

Hide look-ups from your ISP

Settings → tick Prefer DoH. Your provider can no longer see which sites you resolve.

Lock the dashboard

Settings → Security: set a password and turn on HTTPS. Takes ten seconds.
